xstar-atomic documentation
==========================

``xstar-atomic`` is a Python package for direct reading and first-pass physics
evaluation of XSTAR's packed ``atdb.fits`` atomic database.

.. warning::

   This is an alpha-stage research package. It is not a full replacement for
   XSTAR. Validate rates and emissivities before using them for publication.
