# xstar_tools 0.6.50 — Benchmark/reference cleanup

## Scope

Distribution `0.6.50` is a productization/package-footprint cleanup built on accepted science revision `0.6.48.12.3.45.3.3.8`. It does not reopen science.

## Active benchmark resources after cleanup

Only these remain under `src/xstar_tools/benchmarks/`:

- `v06486_qualification_reference_v0472/reference_radiation_v0472_full.csv`
- `v06486_qualification_reference_v0472/trajectory.csv`
- `v0648724_call1_thermal_leaf_reference/trajectory.csv`
- `v0648724_call1_thermal_leaf_reference/v0472_call1_thermal_budget.csv`

The first two support frozen standalone-C++/diagnostic reference lookup. The v0648724 pair is temporarily retained because frozen `xstar_standalone.cpp` references the call-1 thermal leaf budget.

## Archived benchmark history

Thirteen unreferenced parity-era benchmark/oracle directories plus the deprecated compiled-case bundle and the full historical v06486 reference bundle are preserved under `historical/qualification/benchmarks/` in the full history-preserving archive.

Old test/development fixtures are under `tests/fixtures/historical/`. The compiled-case test subset retains only `trajectory.csv` and the 64-bin radiation grid; the full ~44 MB fixture is not duplicated there.

## Packaging

`pyproject.toml` now packages only the two retained benchmark reference directories. Normal distributions do not include the deprecated compiled-case bundle or archived parity-era benchmark directories. `acceptance.py`, `matrix.py`, and `smoke.py` were removed from the benchmark package.

## Freeze invariant

Pinned C++ scientific sources are unchanged. Production-zone ABI remains `6048110`. The parity-freeze checker enforces the reduced benchmark layout in addition to the pre-existing scientific source hashes and comparator/ABI pins.
