# Python guide

The Python interfaces cover two complementary tasks:

1. stable orchestration of XSTAR runs through `XStarConfig` and `run_xstar`;
2. direct inspection and analysis of the packed XSTAR atomic database through `XSTARAtomic` and specialist modules.

They also include readers for XSTAR FITS products and Python wrappers around the native XSTAR2XSPEC planner/table pipeline.
