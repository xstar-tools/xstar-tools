Latest package note: v0.3.118 makes Mg XI / Ca XIX local-state validation usable with preserved XSTAR `xout_abund1.fits` files. `examples/50_mg_ca_xstar_local_state_audit.py` now reads the ASCII-table `ABUNDANCES` extension in `xout_abund1.fits` even on systems where `astropy` is unavailable, via lightweight FITS helpers in `xstar_atomic.xstar_outputs`. The audit correctly treats XSTAR `ion_parameter` in the Mg/Ca target grid as the printed log10(xi) run value and writes both `xstar_log_xi_local` and linear `xstar_xi_erg_cm_s^-1`. With the supplied `xstar_runs` products, the audit recovers local XSTAR temperatures and electron densities for all 12 Mg/Ca log-xi cases and for the explicit Mg XI/Ca XIX xi=3 solver outputs. No default solver physics changed and no triplet scale fitting was added.
